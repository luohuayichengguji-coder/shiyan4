# 本项目使用的 Skills Markdown 审批材料

说明：

1. 本项目首先读取并依据 `AI技术-实验4.1-实验要求-医学图像技术调研.txt` 执行。
2. 本文件夹保存的是本次项目使用到的 skill Markdown 入口、关键工作流和审查用途说明。
3. 每个文件均记录原始 skill 路径、使用阶段、用途和关键内容摘要。
4. 完整调用轨迹另见：`outputs/AI_environment_and_skill_trace.md`。
